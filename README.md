# enaclee.skill

Пиксельный разум для рынка. Сайт-оболочка, которая исполняет **zip-скиллы** прямо в браузере — без сервера, без сборки, без ключей.

> Скилл — сердце системы. Без загруженного zip сайт не запустится.

## Запуск

**Вариант 1 (проще всего):** открыть `enaclee.html` двойным кликом. Всё уже внутри: шрифты, zip-движок, логика.

**Вариант 2 (GitHub Pages):**
1. Создай репозиторий, например `enaclee.skill`
2. Положи `enaclee.html` в корень как `index.html`
3. Settings → Pages → ветка `main`, папка `/ (root)`
4. Сайт живёт на `https://твой-ник.github.io/enaclee.skill/`

## Как это работает

1. **Лендинг** — падающий пиксельный песок, реагирует на курсор/палец
2. **Загрузка скилла** — перетащи zip (например `market-mind-v5.1.zip`) или выбери файл. Сайт проверяет структуру: серьёзные ошибки (нет манифеста, битый JSON, exe-файл, битый граф) — отказ с объяснением; предупреждения — можно
3. **«Перейти в рабочее пространство»** — пять блоков:

| Блок | Что внутри |
|---|---|
| **ЧАТ** | агенты скилла (РЕЖИМ/ТРЕНД/ПОТОК/ДЕРИВ/ТОЛПА/СОВЕТ/РИСК/ОБУЧЕНИЕ), кнопки «Провести аналитику», «Прогноз ЛОНГ/ШОРТ» — по живым данным Bybit/Binance/F&G |
| **ОФИС** | плавающие окна: вход на биржи (Bybit/Binance — ключи только в localStorage, сайт не торгует), конфиг лимитов/комиссий, рынок, о системе. Окна двигаются, масштабируются, **вращаются** |
| **РАЗУМ** | нодовый граф логики скилла: ноды-данные → ноды-аналитики → совет → ворота. Каждую ноду можно открыть, переписать, удалить; новые ноды добавляются из палитры и связываются проводками (циклы запрещены). «ЭКСПОРТ ZIP» скачивает модифицированный скилл |
| **НОВОСТИ** | анонсы бирж (листинги/делистинги/фандинг) + мировые/налоговые, категории, сентимент-разметка, отметки прочитанного |
| **РЕЗУЛЬТАТЫ** | история анализов, статистика (winrate/R/brier), авто-сверка прогнозов с рынком через 4 часа, гипотезы из промахов (работа над ошибками), экспорт CSV |

## Формат скилла

Zip с манифестом `ENACLEE.json` в корне (или в одном вложенном каталоге):

```json
{
  "enaclee": "1.0",
  "skill": "market-mind",
  "version": "5.1",
  "agents":  [ {"id","title","role","module","color"} ],
  "api":     { "klines": {"bybit","binance"}, "funding", "oi", "lsr", "fng", "news" },
  "chat":    [ {"id","label","action","hint"} ],
  "nodes":   { "groups", "node_types", "initial_graph" },
  "validation", "storage"
}
```

Валидатор требует: `skill`, `version`, `agents` (с id/title/role), `api.klines`, `nodes.node_types` (с id/group/title), целостный граф. Исполняемые файлы внутри — мгновенный отказ.

## Технически

- один самодостаточный HTML (~310 КБ): инлайн CSS/JS, шрифт Pixelify Sans (дополнен кириллицей О/П) в base64, zip через fflate
- движок — порт Python-скилла market-mind v5.1 на JS: регимы, 4 аналитика, совет с cross-validation и REVISIT, ворота риска, p_hat-калибровка. Проверено паритет-тестом: 30/30 сценариев совпадают с Python-эталоном бит-в-бит
- данные: публичные CORS-эндпоинты Bybit v5 / Binance fapi / alternative.me F&G — без ключей
- хранение: localStorage (журнал, гипотезы, результаты, позиции окон, граф)
- мобильные: touch-drag окон, pinch-zoom графа, safe-area, адаптив от 360px
- сайт **не торгует** и не отправляет ордера; любые ключи остаются в браузере
